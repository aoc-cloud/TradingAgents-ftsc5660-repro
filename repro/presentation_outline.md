# Zoom 录屏讲解提纲（≤15 分钟）

## 开场（1 分钟）
- 我复现的是 TradingAgents（arXiv:2412.20138），一个模拟交易公司的多 agent LLM 框架
- 论文的核心主张：分析师团队 + 多空辩论 + 风控审核的架构能跑赢买入持有
- 我的复现目标：论文 Table 1 的 2024 Q1 回测（AAPL/GOOGL/AMZN，TradingAgents CR 26.62/24.36/23.21% vs B&H -5.23/7.78/17.1%）

## 怎么做的（3 分钟）
- 按作业 edge case A：模型换成 DeepSeek（flash 快思考层 + v4-pro 深度层），任务、窗口、评分思路一致
- 用仓库自带 backtest：论文窗口每 14 天采样，3 票 × 7 日 = 21 格，5 日持有期，alpha 对 SPY
- 屏幕演示：repro/run_backtest.sh、baseline.py、生成的报告和 memory log 结果表

## 复现结果（3 分钟）
- 定性：流水线完整复现（并行分析师 → 辩论 → Trader → 风控 → 组合经理），决策可解释、数据 point-in-time 核验
- 定量：我们的 hit rate / mean alpha 数字 vs B&H 基线 (+0.17%/格) vs 论文数字
- 为什么和论文数字不可直接比（诚实声明）：
  1. repo 已进化到 v0.7.1，README 自己声明回测不保证与论文一致
  2. 模型不同（DeepSeek vs GPT-4o）
  3. 评分方式不同：论文是日频组合模拟（CR/SR/MDD），现版是独立格 5 日方向性评分
  4. 历史新闻/社媒数据不可得（live feeds 无 2024 存档），情绪数据基本为空
  5. 连论文的 AAPL B&H 基线（-5.23%）都与 yfinance 同窗口 (-10.8%) 对不上，而 GOOGL/AMZN 只差 ~1.5pp → 基线口径不可完全还原

## 修改（3 分钟）
- 消融：关掉研究员辩论（max_debate_rounds 1→0），其余全部不变，同一 21 格重跑
- 动机：直接检验论文的核心主张「辩论显著提升表现」
- 结果：hit rate / mean alpha 前后对比 + 决策文本的定性差异（如评级分布变化）

## 教训与建议（2 分钟）
- 复现 agentic 交易系统最大的障碍不是代码，而是：历史数据可得性、LLM 非确定性、repo 演化
- 给未来同学的建议：锁定 repo 版本 + 固定评分网格做方向性对比；先跑通单格再上扫描；SSL/证书坑提前处理
